# Jev Atlas 精密基础设施视觉重构

日期：2026-09-24  
状态：待用户最终审阅  
范围：现有 Astro 静态站的全站视觉与交互重构

## 1. 目标

将 Jev Atlas 从常见的深色 AI 落地页风格，重构为面向开发者的“精密技术工具 / 技术出版物”。设计应通过排版、信息结构、真实数据和细节建立科技感，避免依赖大面积渐变、柔光、胶囊标签、等权卡片和装饰性终端界面。

本次保留现有品牌名称、科技 Logo、内容、路由、双语、搜索逻辑、SEO、无 JavaScript 浏览能力和 Astro 静态架构。视觉参数为：变化度 7、动效强度 4、信息密度 5。

## 2. 设计原则

1. **真实信息形成界面**：状态、数字、日期和分类只来自发布清单，不生成虚假运行日志、吞吐量、模型指标或终端输出。
2. **结构产生科技感**：使用精确对齐、编号、规格表、细分隔线和有限色彩，不用装饰性光晕填补空白。
3. **阅读优先**：目录首先服务项目发现，项目名称、摘要、分类、源码状态和使用条件必须能快速扫描。
4. **克制的品牌表达**：冷青色只标记交互、当前状态和关键数据；粉色不再作为通用强调色，可在必要的独立状态中少量保留。
5. **全站一致**：首页、目录、分类、搜索、详情、提交、赞助、关于、隐私和 404 共用同一视觉语法。

## 3. 视觉系统

### 3.1 色彩

- 页面底色使用接近黑色的石墨色，而非纯黑。
- 导航、列表行和事实栏使用轻微不同的表面明度建立层级。
- 主文字为冷白色，正文和说明文字保持足够对比度。
- 冷青色用于链接、焦点、当前状态、序号和少量关键数据。
- 边框为低饱和蓝灰色，层级主要依靠单像素分隔线。
- 不使用大面积径向渐变、彩色网格背景或持续发光。

实际令牌在实施计划中固化，所有颜色需通过 WCAG AA 对比检查。

### 3.2 字体

- 英文界面自托管 IBM Plex Sans，覆盖常用正常和半粗字重。
- 技术编号、元数据、日期和小型状态使用 IBM Plex Mono。
- 中文使用系统黑体回退栈，避免拉取不必要的大型中文字体文件。
- 标题以紧凑行高和适度负字距建立力度；正文保持舒适行长和行距。

### 3.3 形状与层级

- 常规圆角限定在 2–6px。
- 搜索框和主要操作可以保留清晰边界，不使用大面积柔和阴影。
- 标签从胶囊形改为文字状态或小型矩形标记。
- 页面区块通过留白、编号、细线和背景明度区分。

## 4. 页面结构

### 4.1 全局导航

- 导航改为紧凑的技术工具栏。
- Logo 与 Jev Atlas 名称固定在左侧，主导航按同一基线排列。
- 当前页面使用细青线或文字状态表示。
- 分类下拉、语言地球图标和移动端导航保持键盘可用及 44px 触控面积。
- 不恢复已删除的顶部关系声明栏。

### 4.2 首页

- Hero 使用非对称双栏，整体左对齐。
- 左栏包含分类眉题、主标题、简介、搜索命令栏和必要操作。
- 右栏展示真实目录状态：发布项目数量、已确认开源数量、最近资料核查日期和双语覆盖情况。
- 搜索仍提交到现有搜索路由，不改变查询参数和无 JavaScript降级。
- 分类区改为 `01` 到 `06` 的编号索引，以规则网格呈现分类名称、项目数量和进入指示。
- 最新项目采用技术索引式行布局，移除大卡片感。
- 提交与合作入口降为清晰的编辑式条带，不与核心目录争夺注意力。

### 4.3 目录与分类

- 页面标题使用同一左对齐系统。
- 项目列表建立稳定信息列：项目身份与摘要、分类、Stars、源码状态、使用条件、详情入口。
- 窄屏按照语义顺序折叠为两层信息行，不创建横向滚动表格。
- 分页继续使用普通链接并保持独立 canonical。

### 4.4 项目详情

- 详情头部突出项目名称、作者、摘要和可信状态。
- 主体采用技术出版物版式，问题、使用条件、来源和相关项目形成清晰章节。
- 右侧事实栏改为规格表，集中展示生态关系、源码状态、许可证、Stars、资料日期和使用条件。
- 移动端事实栏进入正文流，不使用粘性定位。

### 4.5 搜索与信息页

- 搜索筛选器使用规则分组和明确状态，不使用浮动玻璃面板。
- 搜索结果复用项目索引式行组件。
- 提交、赞助、关于和隐私页使用统一的编辑式标题、正文宽度、旁注和联系操作。
- 404 使用相同编号与导航语言，不制作戏剧化插画或无关动画。

## 5. 交互与动效

- 入场、焦点和悬停反馈控制在约 120–240ms。
- 项目行悬停只改变左侧状态线、背景明度和行尾箭头；行本身不横向漂移。
- 搜索框表现为命令输入区，但保留原生 label、表单提交和可见焦点。
- 不使用循环动画、扫描线、鼠标跟随光效或持续粒子效果。
- `prefers-reduced-motion` 下取消非必要位移和过渡，内容始终直接可见。

## 6. 实现边界

- 保留 Astro、TypeScript、Tailwind CSS 和 JSON 内容架构。
- 不引入 React、全站 SSR、运行时 AI、数据库或新的付费服务。
- 不修改项目数据事实、分类逻辑、搜索算法、URL、canonical、hreflang、sitemap 或索引规则。
- 字体必须自托管并纳入静态资源；只包含实际使用的字重和字符子集。
- 继续使用现有 Jev Atlas Logo、favicon 和社交分享图。
- 允许重构 CSS 令牌和页面组件标记，以建立清晰、可维护的视觉系统。

## 7. 响应式与无障碍

- 核心视口：375px、768px、1440px。
- 所有页面不得产生整体横向溢出。
- 独立交互控件保持至少 44px 触控尺寸。
- 保留跳转到正文、键盘导航、可见焦点、表单 label、真实 404 和无 JavaScript 浏览。
- 自动化检查继续覆盖 WCAG AA，并对主文字、次要文字、链接和焦点状态做人工对比复核。

## 8. 验收标准

1. 首页不再使用居中大标题、光晕背景、按钮云和规则卡片作为主要视觉语言。
2. 六个分类均以编号索引呈现，项目数量来自真实数据。
3. 项目列表在桌面形成稳定信息列，在 375px 保持清晰阅读顺序和操作可达性。
4. 首页、目录、分类、搜索、详情和信息页使用一致的排版、边框、状态和动效系统。
5. 所有现有功能、SEO、双语、无 JavaScript和 404 行为无回归。
6. `npm run check`、`npm test`、预览构建、生产构建及完整 Playwright 套件通过。
7. 使用桌面与移动端截图进行全站设计审查，修复明显的模板化、对齐、层级、密度和溢出问题。
8. 验收证据写入 `reports/acceptance/`，唯一进度状态更新到 `docs/PROJECT_PLAN.md`。

## 9. 非目标

- 不重新命名 Jev Atlas。
- 不重新生成 Logo 或 favicon。
- 不新增业务功能、账号、收费能力或内容来源。
- 不承诺搜索排名、访问量或转化提升。
- 不部署、修改 DNS 或提交搜索引擎平台；这些仍属于 M4-04 的线上工作。
